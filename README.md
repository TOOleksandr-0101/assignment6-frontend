Assignment #6: jQuery (Selectors, Effects, Animations)

This project demonstrates core features of the jQuery library:
- Part 1: Getting Started with jQuery (CDN setup, document.ready, selectors, text/html, and CSS manipulation)
- Part 2: jQuery Effects (show/hide/toggle, fadeIn/fadeOut/fadeToggle, slideUp/slideDown/slideToggle)
- Part 3: DOM Manipulation with jQuery (append, prepend, remove, attr modification, and real-time form inputs)
- Part 4: Animations (basic, sequential, and combined .animate() calls)
- Part 5: Mini Project — Interactive Accordion Menu with smooth slide animations
